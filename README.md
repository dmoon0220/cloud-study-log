# Cloud Study Log

AWS와 DevOps를 공부하면서 배운 내용을 기록하고 복습하는 웹 서비스입니다.

## 주요 기능

- 공부 기록 등록
- 공부 기록 목록 조회
- 복습 상태 변경
- 공부 기록 삭제

## 사용 기술

- Java 21
- Spring Boot
- Thymeleaf
- Spring Data JPA
- MySQL 8.4
- Docker Compose
- Gradle
